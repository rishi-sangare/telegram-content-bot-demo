# Telegram Content Bot (demo)

A Telegram bot that runs a content team's workflow, built natively in Make.com: briefs, approvals and revisions, automatic Google Drive upload detection, and Asana tasks.

**Watch the 3.5-minute walkthrough:** https://rishi-sangare.github.io/telegram-content-bot-demo/

This repo holds the demo page and video.
